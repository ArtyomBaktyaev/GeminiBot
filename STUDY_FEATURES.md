# Учебные функции (добавлены поверх существующего бота)

Существующий `bot.py`, пул Gemini, напоминания, группы, темы и health-check сохранены. Новые команды находятся в `study_features.py` и используют отдельный `study_data.json`, чтобы не ломать старые файлы состояния. Если включён Gist, новый файл также синхронизируется.

## Команды
- `/study` — справка по учебным функциям.
- `/lesson Пн 09:00 Математический анализ | 302 | Иванов | чётная` — добавить пару. День: Пн/Вт/Ср/Чт/Пт/Сб/Вс; время `ЧЧ:ММ`; необязательные поля — аудитория, преподаватель, тип недели (`любая`, `чётная`, `нечётная`).
- `/schedule` — всё расписание; `/schedule сегодня`, `/schedule завтра`, `/schedule ср` — просмотр выбранного дня.
- `/ics` — выгрузить повторяющиеся занятия в календарный файл `.ics` (пары экспортируются как 90-минутные события на 16 недель).
- `/card word | перевод | пример` — добавить английскую карточку.
- `/cards` — повторять карточки; кнопки показывают перевод и учитывают ответы. Неизвестные слова возвращаются через 10 минут, известные получают увеличивающийся интервал.
- `/quiz тема` — подсказка для запуска квиза через уже подключённый Gemini. Полноценные Telegram Quiz Polls, статистика по вопросам и режим экзамена пока не реализованы.

## Важные границы текущего этапа
- Расписание пока добавляется командами, а не автоматически из фотографии/PDF; проверка распознавания кнопками «Верно/Исправить», разовые исключения и уведомления за 30 минут ещё не подключены.
- Утренний дайджест, кнопка «Сдал», экспорт задач, автоматическое извлечение карточек из текста/лекций и админская `/stats` ещё не подключены.
- Данные учебного раздела хранятся в отдельном JSON-файле и могут синхронизироваться через уже существующий Gist. Миграция на Neon/Supabase/Turso и Telegram Mini App — следующие отдельные этапы; в этой версии не заявляются как готовые.
- Для устойчивого хранения на бесплатном Render настрой Gist как в существующем README либо подключи постоянный диск/БД. Сам по себе JSON на эфемерном диске Render не гарантирует сохранность.
