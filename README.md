# 🎓 Academic Gemini Bot

Telegram-бот — академический помощник для группы с топиками (форум-ветками). Работает на **aiogram 3** и **Gemini** (`google-genai`).

## Возможности

- Ответы Gemini в группе (`Гемини, реши…` или упоминание бота) и в личке; контекст ветки — скользящее окно.
- Режим ответов в `/settings`: **«Подробный разбор с теорией»** / **«Краткий ответ (шпаргалка)»**.
- Публикация напоминаний в нужный топик (Function Calling) + список задач и дедлайнов **`/tasks`** (`tasks.json`).
- Фото конспектов (авто-ресайз до 1600 px), документы PDF / DOCX / текст, **голосовые сообщения**.
- Пул API-ключей Gemini с автоматической ротацией (429, 401/403, 5xx) и «остыванием» ключей.
- Безопасное форматирование: Markdown от модели → Telegram HTML, при отказе — чистый текст (никаких `can't parse entities`).
- Длинные ответы режутся по абзацам; блоки кода не ломаются.
- Индикатор «печатает… / отправляет документ…» всё время работы.
- Health-check сервер (`/health`) для Render.

## Быстрый старт (локально)

```bash
git clone <твой-репозиторий> && cd <папка>
pip install -r requirements.txt
cp .env.example .env      # заполни TELEGRAM_BOT_TOKEN и GEMINI_KEYS
python bot.py
```

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен от @BotFather |
| `GEMINI_KEYS` | да | ключи Google AI Studio через запятую |
| `TARGET_CHAT_ID` | нет | ID основной группы (по умолчанию как в коде) |
| `ALLOWED_CHAT_IDS` | нет | ID дополнительных групп через запятую (их можно подключать и командой `/addgroup`) |
| `ADMIN_IDS` | рекомендуется | Telegram ID админов через запятую; иначе настройки и лимиты доступны всем, кто напишет боту в личку |
| `GEMINI_MODEL` | нет | по умолчанию `gemini-3.8-flash` |
| `BOT_TZ` | нет | часовой пояс для дедлайнов, по умолчанию `Europe/Moscow` |
| `HISTORY_WINDOW`, `MAX_MEDIA_PER_THREAD`, `MEDIA_BUDGET_MB` | нет | лимиты памяти ветки (RAM) |
| `GIST_ID`, `GIST_TOKEN` | нет | сохранение `topics/tasks/settings` в секретный Gist |

> ⚠️ **Никогда не коммить токены и ключи.** Они хранятся только в `.env` (в `.gitignore`) или в секретах хостинга.

## Настройка группы

1. В @BotFather: `/setprivacy` → **Disable**, чтобы бот видел сообщения группы. Добавь бота в группу.
2. Привязка топика: напиши в нужной ветке `тема Английский` (или `Гемини, тема Английский`). Темы хранятся отдельно для каждой группы.
3. Дополнительная группа: добавь бота, отключи privacy mode и напиши в группе `/addgroup` (только админы). `/chatid` покажет ID чата и ID темы, `/removegroup` отключает группу.
   В личке (⚙️ Настройки → 🏷 Темы группы) админ видит группы и их темы раздельно; Gemini при просьбе из лички публикует в нужную группу по названию, а из группы — только в неё. Задачи `/tasks` тоже раздельные: в группе — её собственные, в личке — все.
4. Узнать ID чата/топика вручную: `python detector.py` (или команда `/chatid`).

## Хостинг бесплатно

### Вариант A. Render (постоянно, 24/7)

1. Залей репозиторий на GitHub → Render → **New → Blueprint** (подхватит `render.yaml`) или Web Service вручную: Build `pip install -r requirements.txt`, Start `python bot.py`, план **Free**.
2. Добавь переменные окружения (см. таблицу).
3. Бесплатный сервис Render засыпает через ~15 минут без входящих запросов. Заведи пинг на `https://<твой-сервис>.onrender.com/health` каждые 5 минут (например, бесплатный [UptimeRobot](https://uptimerobot.com) или [cron-job.org](https://cron-job.org)).
4. Диск Render **временный**: `tasks.json` и настройки пропадают при перезапуске. Включи Gist (ниже).

**Gist-хранилище (рекомендуется для Render и Actions):** создай секретный Gist с файлом `topics.json` (содержимое `{}`), получи токен со scope `gist`, укажи `GIST_ID` и `GIST_TOKEN`. Бот сам подтянет состояние при старте и будет выгружать изменения.

### Вариант B. Запуск по требованию из GitHub Actions («включить когда угодно и откуда угодно»)

В репозитории есть `.github/workflows/run-bot.yml`.

1. Repo → Settings → Secrets and variables → Actions → добавь секреты `TELEGRAM_BOT_TOKEN`, `GEMINI_KEYS`, `TARGET_CHAT_ID`, `ADMIN_IDS`, `GIST_ID`, `GIST_TOKEN`.
2. Запуск: вкладка **Actions → Run bot (on demand) → Run workflow** — с компьютера или из мобильного приложения GitHub. Бот работает до 5 часов, повторный запуск заменяет предыдущий.
3. Запуск одной кнопкой с телефона: Shortcuts (iOS) / HTTP Shortcuts (Android) с запросом
   `POST https://api.github.com/repos/<user>/<repo>/actions/workflows/run-bot.yml/dispatches`, тело `{"ref":"main"}`, заголовок `Authorization: Bearer <fine-grained токен с правом Actions: write>`.

Замечания: в публичных репозиториях минуты Actions бесплатны, в приватных ограничены (около 2000 мин/мес). Правила GitHub не предполагают использование Actions как постоянного хостинга, поэтому этот вариант — для сессий «по требованию», а не для работы 24/7.

### Вариант C. Свой компьютер или VPS

`python bot.py` или systemd-сервис. Например, Oracle Cloud Always Free VM даёт настоящий 24/7 без засыпаний.

> Одновременно должен работать **только один** экземпляр бота (Render, Actions или локально), иначе Telegram вернёт `409 Conflict`.

## Напоминания, задачи, стикеры

- Напоминания оформляются ярко: заголовок с эмодзи, срок, предмет, задание, ссылка и мотивирующая фраза.
- К каждому напоминанию бот добавляет случайный стикер или GIF из вашей коллекции: ⚙️ Настройки → 🎭 Стикеры и GIF → «Добавить», затем пришлите стикеры или GIF.
- Из лички можно просить: «Сделай напоминание в УНН в теме гум до 25.10, вставь эти 2 файла и ссылку…». Короткие названия групп задаются в самой группе командой `/alias унн, unn` (только админы).
- «Гемини, задание выполнил / сдал / готово» — бот отметит подходящую задачу выполненной и уберёт её из `/tasks` (только админы).

## Файлы: PDF, Word, Excel, PowerPoint

Попросите бота: «Гемини, опиши, что делает каждая команда в этом коде, ответ пришли в PDF» (или Word / Excel / «сделай презентацию»). Бот напишет ответ, соберёт из него оформленный документ и отправит файлом. Подходит и для ответов, которые не помещаются в одно сообщение Telegram.

- **PDF и Word** — шапка с названием, заголовки, списки, таблицы, блоки кода с подсветкой фона, номера страниц.
- **Excel** — таблицы с цветной шапкой, фильтрами и закреплённой строкой, числа и формулы (`=SUM(...)`) распознаются; каждая таблица на своём листе.
- **PowerPoint** — титульный слайд и слайды «заголовок + пункты», таблицы и код; длинное автоматически делится на несколько слайдов.
- Файл можно отправить в нужную тему: «…в PDF и отправь в группу УНН в тему информатика». Сгенерированный файл потом можно прикрепить к напоминанию («прикрепи этот файл»).
- Для PDF нужен шрифт с кириллицей: бот берёт DejaVu из папки `fonts/` или системы либо сам скачивает его при первой генерации. Эмодзи в PDF не отображаются (в Word и PowerPoint — отображаются).
- На Render рекомендуется Python 3.12 (файл `.python-version` или переменная `PYTHON_VERSION=3.12.7`).

## Расписание, квизы, карточки, мини-приложение

Эти функции вынесены в отдельные модули рядом с `bot.py`: `ext_timetable.py`, `ext_study.py`, `ext_webapp.py` и страницу `webapp/index.html`. Без любого из них бот просто работает без этой функции.

- **Расписание.** Пришлите боту в личку фото, скриншот, PDF или текст с парами: он разберёт и покажет черновик с кнопками «Сохранить / Исправить / Отмена». Кнопки «Сегодня / Завтра / Неделя», выбор дня. Правки словами: «перенеси физику на среду на 11:30», «завтра первой пары нет», «сейчас нечётная неделя», «присылай сводку в 7 утра», «напоминай за 15 минут». `/ics` — экспорт в календарь.
- **Квиз.** «Гемини, сделай квиз по теме … / по этому файлу» — 5 вопросов обычными квиз-опросами Telegram, результат, разбор ошибок и кнопка «Повторить ошибки».
- **Карточки.** «Добавь карточки: ubiquitous, mitigate» — перевод, транскрипция, пример. `/cards` — повторение «Знал / Не знал» по системе Лейтнера, в утренней сводке видно число карточек к повторению.
- **Кнопка «Я сделал(а)»** под напоминаниями с дедлайном; в `/tasks` видно, кто сдал.
- **/stats** — состояние ваших ключей Gemini (время ответа, ошибки, паузы).
- **Мини-приложение** — кнопка «📱 Приложение» в меню бота: главная, расписание с редактированием, задачи, карточки и квизы, чат с историей, настройки. Открывается по адресу `https://<сервис>.onrender.com/app`, доступно только пользователям из `ADMIN_IDS` (подпись Telegram проверяется токеном бота). Нужно задать `ADMIN_IDS`; адрес сервиса на Render подставляется сам, иначе задайте `WEBAPP_URL`.
- Данные хранятся в `timetable.json`, `study.json`, `history.json` (и в Gist, если он подключён).

## Повторные напоминания и таймеры

- «Гемини, сделай напоминание в теме … до 24.10 и напоминай каждый день» — бот публикует напоминание и дальше сам пишет каждое утро (по умолчанию 09:00 МСК, `DAILY_HOUR`) до дедлайна; в день дедлайна — утром и за 3 часа. Остановить: «Гемини, задание выполнено» или кнопка ✅ в `/tasks`.
- Куда слать повторы: «в главной» (общая лента группы), «мне в лс» или в конкретную тему; по умолчанию — в ту же тему. Предупреждения заранее: «и за час до срока».
- Таймеры: «Гемини, напомни мне через 3 часа и предупреди за 30 минут» или «сегодня в 18:30». Время считается по `BOT_TZ` (по умолчанию `Europe/Moscow`).
- Расписание хранится в `schedule.json` (и в Gist). Чтобы оно не терялось, сервис должен не засыпать (пинг на `/health`) и должен быть включён Gist. Напоминания, опоздавшие больше чем на 3 часа (бот спал), не отправляются.
- `/tasks` — навигация «группа › тема › задачи» (в группе: «тема › задачи»). Значки: 🔔 — есть запланированные напоминания, ⏲ — таймер.

## Как работает память

Хранится не больше `HISTORY_WINDOW` реплик на ветку и `MAX_MEDIA_PER_THREAD` вложений, плюс общий бюджет `MEDIA_BUDGET_MB`. Старое выбрасывается из RAM, файлы Gemini File API удаляются. Подходит для Render 512 МБ.

## Если что-то не работает

- `409 Conflict` — запущен второй экземпляр бота.
- Бот молчит в группе — не отключён privacy mode или чат не совпадает с `TARGET_CHAT_ID`.
- «Все ключи на паузе» — исчерпаны лимиты на всех ключах, подожди или добавь ключи.
- Ошибка модели — проверь `GEMINI_MODEL` в AI Studio.
